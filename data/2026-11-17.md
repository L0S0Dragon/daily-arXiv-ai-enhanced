Motivation: Standard logical memory experiments probe mainly spatial faults, leaving temporal (timelike) error chains and time-correlated error sources poorly characterized; scaling fault-tolerant QEC requires suppressing errors in both space and time, so dedicated experiments sensitive to temporal faults are needed.

Method: Realize and scale the surface code stability experiment on a 105-qubit Willow superconducting processor for patch sizes 3×3 to 7×7; extend the experiment over many cycles to probe time-correlated behavior; construct a parameter-free device-level leakage model incorporating higher-state transport during syndrome extraction; design a walking stability circuit to suppress leakage-induced error; and apply adaptive syndrome-extraction termination based on decoder confidence in offline analysis.

Result: Measured timelike block suppression factor μ_T = 1.47 ± 0.25 showing temporal error suppression is maintained as qubit count grows; observed sum-of-exponentials error suppression from temporally correlated data-qubit heating to |3⟩, fully captured by the leakage model; walking stability circuit achieves logical error probability floor ≤3.20×10⁻⁸ at 60 cycles, two orders of magnitude below the standard construction, limited by ionizing radiation error bursts; adaptive termination reduces spacetime logical error by 38% and time overhead by 34% versus optimal fixed-cycle strategy.

Conclusion: Temporal error suppression scales with patch size in the surface code stability experiment; temporally correlated leakage is a dominant, modelable error source that can be mitigated via circuit design and decoder-driven adaptive termination, establishing practical routes toward scaling fault-tolerant QEC in both space and time.

Abstract: Scaling fault-tolerant quantum error correction (QEC) requires suppressing errors in both space and time, yet standard logical memory experiments primarily probe spatial faults. Here, we use a 105-qubit Willow superconducting quantum processor to realize and scale the surface code stability experiment, which is alternatively sensitive to temporal error chains. Scaling from patch sizes of $3 \times 3$ to $7 \times 7$, we realize a timelike block suppression factor of $μ_T = 1.47 \pm 0.25$, demonstrating the ability to maintain temporal error suppression as the number of qubits increases. By extending the stability experiment for many cycles, we uncover a sum-of-exponentials behavior in error suppression caused by a temporally correlated error: data-qubit heating to the third excited state $|3\rangle$. We fully capture this effect with a parameter-free, device-level leakage model incorporating higher-state transport during syndrome extraction cycles. To suppress this error, we develop and realize a walking stability circuit, reaching a logical error probability floor of $\le 3.20\times 10^{-8}$ at 60 cycles---two orders of magnitude below the standard construction---and limited by ionizing radiation error bursts. Finally, by adaptively terminating syndrome extraction based on decoder confidence in an offline analysis, we reduce spacetime logical error by 38% and time overhead by 34% compared to the optimal fixed-cycle strategy.
